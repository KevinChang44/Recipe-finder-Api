Simple website to retrieve single recipes from TheMealDB api with their thumbnail, name, category and ingredients

You can add recipes to a favorites list, each list belonging to one user

Steps to get the project running locally:

Clone the repo: git clone https://github.com/KevinChang44/Recipe-finder-Api.git
Install dependencies: npm install (root folder) -> cd backend -> npm install (again)
Copy .env.example to a new file named .env and fill in your mysql database credentials.
Run "node server.js" in the backend folder
